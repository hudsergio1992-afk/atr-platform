# Стройплатформа АТР

Веб-платформа управления строительными объектами для ООО «АгроТехРешение».

Модуль 1 (MVP): **Объекты** — карточка объекта, статусы, история изменений.
Остальные модули (график работ, СНЗ, ПТО, снабжение, сметы, контроль, роли) — в разработке.

## Стек

- Next.js (App Router) + TypeScript
- Supabase (Postgres + REST API) — хранилище данных
- Vercel — хостинг

## Локальный запуск

1. Скопируйте `.env.example` в `.env.local` и заполните значениями из Supabase (Project Settings → API).
2. `npm install`
3. `npm run dev`

## Деплой

Проект подключён к Vercel через импорт этого репозитория. При пуше в `main` — автодеплой.
